# 🚀 Multi-Step Form Wizard

A modern and responsive multi-step registration form built using HTML5, CSS3 and Vanilla JavaScript.

## 📌 Project

VEDA Technology - Level 2 Day 13

## 🎯 Objective

Build a multi-step form with:

- Progress indicator
- Step navigation
- Per-step validation
- Form state management
- Final review page
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Regular Expressions
- Responsive Design

## ✨ Features

### 1. Personal Information

Users can enter:

- First Name
- Last Name
- Email
- Phone Number

### 2. Account Information

Users can enter:

- Username
- Password
- Confirm Password
- Course

### 3. Address Information

Users can enter:

- Address
- City
- State
- PIN Code

### 4. Review

The final step displays all entered information before submission.

## ✅ Validation

The project validates each step before allowing the user to continue.

Examples:

- Required fields
- Valid email format
- 10-digit phone number
- Minimum password length
- Matching passwords
- Valid 6-digit PIN code

## 📱 Responsive Design

The form works on:

- Desktop
- Laptop
- Tablet
- Mobile
